# v0.0.1 - 2026-06-20

模板初始版本。

> 本目录是 `CHANGELOG.md` 的历史归档。主文件只保留最新 5 个版本，更旧版本完整记录在此（每个版本一个 `vX.Y.Z.md`）。

## 新增

- **工程骨架**：基于 TabooLib 6.3.0 的 Gradle 多模块结构。
  - `api`：对外契约模块，配置 `maven-publish` + `withSourcesJar()`，发布坐标 `top.wcpe.mc.plugin.template:templateplugin-api`。
  - `project:core`：业务实现模块，接入 KSP + EasyQuery 3.1.82 持久化、JUnit 5 测试。
  - `plugin`：组装模块，`taboolibIoc` 自动接管，打包 `api` + `core` 产出最终插件 JAR。
- **依赖注入**：`top.wcpe.taboolib.ioc` 0.0.5。
- **工程规范**：`.claude/rules/` 下注释、配置文件、测试、对外 API 语言、Git 提交规范。
- **发版技能**：`.claude/skills/release-version/SKILL.md`，规范本地发版流程（版本推导、文档同步、构建验证、打 tag）。
- **项目文档**：README、ARCHITECTURE、API（`docs/API.md`）、CONTRIBUTING、CHANGELOG。
- **开源协议**：MIT（`LICENSE`）。

## 备注

- 本版本为纯模板骨架，暂无业务源码（`src/`）。
- 首次使用需按 [README.md](../../README.md) 的"首次使用修改清单"替换项目标识。
